# WebGIS Desa Adat Sibetan

WebGIS Desa Adat Sibetan dibuat menggunakan **QGIS** dan diekspor menjadi peta interaktif berbasis web melalui plugin **qgis2web**.

Lokasi salak yang ditampilkan merupakan **lokasi potensial tanaman salak** yang diidentifikasi berdasarkan hasil klasifikasi citra satelit **Sentinel-2** menggunakan algoritma **Random Forest Classifier (RFC)**.
